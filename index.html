How this v1 works

        

        
      

      

        

          This tool reads a raw Moodle XLSX export, matches students by their
          Moodle Username / Obsidian ID, maps Moodle groups to tutors, and
          proposes changes to your existing student Markdown files.
        

        

          Scanning is read-only. Nothing is written when you
          scan or preview. Existing notes are never replaced wholesale.
        

        

          For an existing student, the current v1 inserts the new course block
          immediately before ## General Feedback and adds the
          course session tag using the existing tags: property
          format.
        

        

          For a genuinely new student, v1 creates a complete record using the
          structure represented by your existing student notes. Every creation
          or modification requires an individual Apply action.
        

        

          The Student level selector controls level: UG or
          level: PG only for newly created student records.
          Existing student frontmatter is preserved.
        

        

          This is a browser application. It processes the selected files
          locally. Your Moodle data and Markdown contents are not sent to this
          site.
        

        

          For v1, use a Chromium-based browser such as Chrome or Edge for the
          local folder read/write features.
